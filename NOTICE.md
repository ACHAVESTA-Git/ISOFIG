# Credits

isofig is an independent rewrite inspired by **[anatomy](https://github.com/wheresryan22/anatomy)** by Ryan
(@wheresryan22), released under the MIT License. The idea that "the object is the explanation", the isometric
four-tone look and the craft rules come from that project. No source code was copied: the core, runtime, adapters
and audit were written from scratch for a declarative spec, build-time SVG and a small weight budget.
